# House rules

A house rule is a standing editing preference, such as "Always keep the pause
before a punchline." Agents working in your video and carousel projects are
told your house rules at the start of every turn.

## Adding a rule

Say the preference in a message, the way you would to an editor: "from now on,
never use the zoom preset on b-roll." Stellar reads what you send in video and
carousel projects and, when it finds a standing preference, offers it above the
composer as one sentence. An agent can offer one too.

- **Approve** saves it for every project.
- **Only this project** saves it for the project you are in.
- **Edit wording** lets you rewrite the sentence before you approve it.
- Dismiss it to save nothing.

Nothing becomes a rule until you approve it. When a new rule contradicts one
you already have, the offer names the rule it replaces.

The check uses your text generation model, the one that names threads, and
runs beside your turn, so it never delays the agent.

## Removing a rule, or turning this off

**Settings > General > Video** lists your house rules; remove one there and the
next turn no longer gets it. Turn off **Notice house rules** in the same place
to stop Stellar reading your messages for preferences. Rules you already
approved stay in force.

Approving and removing rules is done in the desktop and web apps. Rules apply
to turns you start from the mobile app as well.
